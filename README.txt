RUNNING THE PROGRAM:

1. Make sure MySQL is running.

2. Open the project folder in IDE.

3. Open the terminal and run:
   mvn clean compile

4. Start the program with:
   mvn exec:java -Dexec.mainClass=Login

5. The login screen will open.
